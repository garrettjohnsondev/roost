The map

A roadmap that reads itself

A roadmap you maintain by hand is a roadmap that drifts — yours already said 114 tests when there were 200, and listed three phases as pending that had shipped. So this one is generated: phases and their state come from the status table, the test count from the suite, corrections from the log. It cannot flatter you, because nobody types it.

Kept current by the gate, not by good intentions. A job that verifies writes its own row; a correction logged by an agent ticks the count. The map changes because the work changed, which is the only way a roadmap stays honest.
