Ask once, then remember the answer

The ladder already exists in the code — dispatch at 40%, compact at 60%, hand off at 80% — and it renders as a line of grey text nobody acts on. Compacting loses detail, so it is never done behind your back. It is offered by the agent whose context it is, at the moment the colour starts leaving them, with a box that stops it asking again.

Cheapest fix first

40% DISPATCH Send the reading to a subagent. Their context fills; this one stays clean. Nothing is lost, so it never asks. FREE
60% COMPACT Summarise the middle of the conversation. Detail goes, so this is the first rung that needs your say-so. ASKS ONCE
80% HAND OFF Start a fresh agent seeded from the plan file. A different decision from compacting, so the checkbox above does not cover it. ASKS AGAIN
WHY 60 AND NOT 95

Every frontier model tested degrades with length, well before its window is full. Waiting for the engine's own auto-compact means acting after the quality has already gone. These thresholds are deliberately tighter than any engine's.

THIS IS NOT THE CHAPTER FOLD

Folding a finished job tidies your view and touches nothing the agents hold. This compacts what an agent remembers. Same word in most tools; two different things here, and only one of them costs you anything.
