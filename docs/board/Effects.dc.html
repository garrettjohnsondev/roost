Beyond the crew

Motion that carries information

Ambient movement is the commonest tell of a generated interface, so none of these run on their own schedule. Each one answers something you did, or reports a state that changed — and each replaces a sentence you would otherwise have to read.

01The stamp
npm test
exit 0 · 261 passed
VERIFIED

A gate passing is the highest-evidence moment in the product. It lands with weight and carries the exit code, not an adjective. Failure stamps red and unfurls the output.

02Fuel actually draining

The block you just spent flares, then goes dim. An abstract percentage becomes a thing you watched leave.

03Use it or lose it
4 BLOCKS EXPIRE IN 40M

Capacity that expires unused pulses; capacity you keep sits still. The surplus rule, made visible instead of a sentence.

04Context rot, visible

As the window fills past degrading, the agent dims and desaturates. You feel quality dropping before a number says so.

05Commands type themselves
$ npm typecheck_

Gate output is terminal text, so it arrives like terminal text. The vernacular belongs to the content, not to a costume.

06The job folds
FMTAGO RENAMEVERIFIED
2 turns · gates passed · diff reviewed

When gates pass the chapter collapses into its named row, so you see where it went and nothing feels lost.

07An agent that needs you
Juno wants to run
rm -rf dist

Approval turns the sprite toward you with one ring of attention. Paired with a haptic tap you can feel it without looking.

08Finishing is worth something

Gates green on a whole job and the crew celebrates, once, briefly. The only unprompted delight in the app, and it has to be earned.

Rationed. One thing moves unprompted: the crew's idle breath. Everything else waits for your action or a real state change. Haptics. A phone can tap you. One pattern for a gate passing, another for failing, a third for an approval — a result you feel before you read it. Hard shadows. A 3px offset in deeper indigo, never a blurred grey one. Soft shadow under every card is the SaaS-kit tell. Reduced motion. Every effect collapses to its final frame. The stamp still reads VERIFIED; it just doesn't land.
