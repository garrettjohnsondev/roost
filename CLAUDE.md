# Notes for AI assistants

- **Asked to install Roost for someone?** Follow [docs/INSTALL-WITH-AI.md](docs/INSTALL-WITH-AI.md) step by step.
- **Working on Roost's code?** `npm install`, then `npm run typecheck && npm test` before any commit. The wire protocol is `server/src/protocol.ts`, mirrored in `web/src/types.ts`. Decisions and their reasons live in `ROADMAP.md`.
